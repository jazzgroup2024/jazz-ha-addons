# Jazz Custom Zigbee2MQTT Add-ons (Multi-Instance 1-30)

Этот репозиторий содержит **30 независимых инстансов (клонов) Zigbee2MQTT** для Home Assistant.

Каждый аддон имеет:
- Уникальный `slug` (`zigbee2mqtt_01` ... `zigbee2mqtt_30`)
- Уникальный порт Ingress / Web UI (`8091` ... `8120`)
- Изолированную папку конфигурации и базы данных
- Автоматическое обновление версий через GitHub Actions
